# 用語與格式

本檔的格式規則多屬〔領域〕慣例；期刊另有規定時，以期刊為準。只做文法或用字修改時，只套用本檔，不要展開其他檢查。

## 物種名稱

- 學名斜體，第一次出現寫全名（*Klebsiella pneumoniae*），之後縮寫屬名（*K. pneumoniae*）；不同屬縮寫相同時（例如 *Enterococcus* 與 *Escherichia*），保留可區分的寫法。
- 「腸桿菌目」用 Enterobacterales；舊稱 Enterobacteriaceae（腸桿菌科）只在指該科或引用舊文獻時使用。
- 複合群要寫清楚，例如 *K. pneumoniae* species complex、*Acinetobacter baumannii-calcoaceticus* complex；用 MALDI-TOF 或生化鑑定時，通常只能鑑定到複合群層級。

## 基因、蛋白與表型

- 細菌基因名稱斜體、首字小寫（*mecA*、*vanA*、*mcr-1*）；蛋白不斜體、首字大寫（PBP2a、MCR-1）。
- β-lactamase 基因寫作 *bla* 加下標的酵素名，例如 *bla*<sub>KPC-2</sub>、*bla*<sub>NDM-1</sub>、*bla*<sub>OXA-48</sub>；酵素本身寫作 KPC-2、NDM-1，不斜體。
- 點突變寫法要一致，並註明編號依據的參考序列，例如 GyrA S83L（胺基酸）或 *gyrA* C248T（核苷酸）。
- 插入序列寫作 IS 加斜體名稱，例如 IS*Aba1*、IS*26*。
- 表型縮寫第一次出現時寫全名：MRSA、VRE、ESBL、CRE、CRAB、CRPA、CPE。

## 抗藥相關用語

| 不建議 | 建議 | 理由 |
|---|---|---|
| 「帶有 *bla*<sub>KPC</sub> 的抗藥菌株」（沒有藥敏結果時） | 「帶有 *bla*<sub>KPC</sub> 的分離株」 | 基因型不等於表現型 |
| resistant（用 ECOFF 判讀時） | non-wild-type | ECOFF 不是臨床判讀標準 |
| resistant（把 I 併入時） | non-susceptible | 明確表示包含 I |
| intermediate（EUCAST 2019 年後） | susceptible, increased exposure | EUCAST 已重新定義 |
| strain（指每一株送驗菌） | isolate | strain 通常指已確認的獨特菌株或譜系 |
| clone（只有同 ST 的證據時） | 同一 ST／同一 cluster | clone 隱含近期共同祖先 |
| transmission（只有基因證據時） | genomically linked／consistent with transmission | 直接傳播需要流行病學佐證 |
| outbreak strain（未確認群聚時） | cluster | 群聚需要流行病學定義 |
| MIC 單位寫 μg/mL 與 mg/L 混用 | 全文統一一種 | 兩者數值相同，混用容易誤讀 |

## 寫作提醒

- 「首次報告」「首例」：需要作者提供文獻檢索依據；沒有時改為「據我們所知」並保留檢索範圍，或刪除。
- 「高度抗藥」「嚴重威脅」等強度詞：要有對應的數值或比較對象。
- 數字與單位：抗藥率同時寫比例與分子分母，例如 45.2%（85/188）。
- 菌株或病人代碼不要出現可識別個人身分的資訊。
